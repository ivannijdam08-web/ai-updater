Link your project folder, type your prompt, and apply all AI file creations, code edits, and deletions to your hard drive with 1 click.

How does AI Folder Sync work?

Link your local folder once and collaborate directly with Google AI Studio without manually copying or creating files.

🚀 New project from scratch (Empty folder)

  1. 1
    Choose an empty folder: In Step 1, select an empty project folder on your computer. The tool automatically informs the AI that the project currently contains 0 files.
  2. 2
    Type your task & copy: In Step 2, describe what you want to build, click Copy Project + Prompt, and paste it into Google AI Studio.
  3. 3
    1-Click build on disk: Click the copy icon on the AI's JSON code block and press ⚡ Read Clipboard & Update Folder. All folders and files are created directly on your drive.

⚡ Ongoing chat & manual edits (Smart Diffs)

  1. 1
    Live Auto-Refresh: When you edit, add, or delete files in VS Code or Explorer, AI Folder Sync detects it automatically in the background.
  2. 2
    Sync manual changes to AI: Use 🔄 Ongoing Chat: Sync Manual Changes + Prompt to send only the files you tweaked locally so the AI updates its memory.
  3. 3
    Safe updates with 1-Click Undo: Every JSON update creates an automatic backup snapshot first, so you can undo any AI update with 1 click.

Key Features

Designed for speed, clarity, and projects of any size.

↩️

1-Click Undo & Auto-Refresh

Before applying any JSON update, an automatic snapshot is saved so you can revert immediately. External edits in your code editor are synced live.

📌

Floating Picture-in-Picture Panel

With Floating Panel, you place the controls in a compact always-on-top window over Google AI Studio, so you never have to switch tabs.

🔍

Smart Search & Replace ("edit")

Unchanged files are omitted from the JSON. Existing files are updated per code block using 3-layer whitespace-tolerant matching.

100% Local & Open-Source

Your source code and files never leave your device to any external server through this tool.

🔒 Full privacy in your own browser

This tool runs completely client-side via the official W3C File System Access API.

  • ✓ Only relevant changes: The AI exclusively returns additions, edits, and deletions.
  • ✓ 0 bytes to external servers: Everything is processed locally in your browser's memory.
  • ✓ Instant disconnect: One click on ✕ Close folder immediately clears the linked folder from memory.
