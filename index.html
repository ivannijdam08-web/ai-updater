Waarom deze tool zo fijn werkt

Gebruik de beste AI-modellen in Google AI Studio zonder API-kosten en zonder handmatig kopiëren en plakken per bestand.

✨ Gratis AI Prompt-Hulp

Typ in je eigen woorden wat je wilt en klik op ✨ Verbeter mijn Prompt met AI. De ingebouwde AI herschrijft je vraag direct naar een glasheldere programmeer-opdracht.

⚡ Geen Dubbele Code Meer

Na je eerste bericht schakelt de tool automatisch over naar Vervolg-Vraag Modus. Je stuurt dan alleen nog je nieuwe vraag en krijgt van de AI alleen de gewijzigde regels terug.

🏗️ Werkt ook met Lege Mappen

Begin je een nieuw project? Kies een lege map op je PC of telefoon en laat de AI automatisch alle mappen (css/, js/) en bestanden vanaf nul opbouwen.

100% Veilig, Lokaal & Open-Source

Jouw bestanden blijven op jouw eigen apparaat en worden nooit naar een server van deze website geüpload.

🔒 Lokale Browser-API

Maakt gebruik van de officiële File System Access API van je browser. Toegang geldt uitsluitend voor de map die jij zelf selecteert.

🛑 Direct te Sluiten

Met één klik op ✕ Sluit map (of zodra je het tabblad sluit) wordt de koppeling met je projectmap direct verbroken.

🔓 Volledig Open-Source

De volledige code van deze tool staat openbaar op GitHub in één leesbaar HTML-bestand zonder verborgen trackers.
